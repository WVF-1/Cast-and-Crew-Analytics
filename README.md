# Cast-and-Crew-Analytics
Continuation of the Movie Month analysis, this time focusing on the human factors rather than the financial insentives.

# 🎬 Cast, Crew & Keyword Intelligence
### May Newsletter — Movie Intelligence Series (Part 2 of 3)

A three-notebook deep dive into the human and thematic drivers of film success, using the TMDB Credits and Keywords datasets merged with the financial baseline established in Part 1. The project moves beyond box office numbers to ask a more interesting question: does it matter *who* makes the film, and *what* it's about?

This is Part 2 of a three-part May newsletter series on movie intelligence. Part 1 covered financial performance analytics; Part 3 will close the loop with audience rating behaviour.

---

## 📊 Datasets

**Source:** [TMDB Movies Dataset](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset) via Kaggle

| File | Rows | Key Fields |
|------|------|------------|
| `credits.csv` | ~45,000 | `cast` (JSON list), `crew` (JSON list), `id` |
| `keywords.csv` | ~46,000 | `keywords` (JSON list), `id` |
| `movies_clean.parquet` | ~4,800 | Carried over from Part 1 |

Both `credits.csv` and `keywords.csv` store their data as stringified JSON lists — a significant portion of NB4 is dedicated to parsing these cleanly. The analysis-ready subset is the same ~4,800-film universe used in Part 1 (budget and revenue both recorded).

> `credits.csv` and `keywords.csv` are not committed to this repo due to file size. Download them from the Kaggle link above and upload them to your Colab session alongside `movies_clean.parquet` before running.

---

## 🚀 Running the Notebooks

The notebooks must be run in order. NB4 depends on `movies_clean.parquet` from Part 1; NB5 and NB6 depend on the parquets generated by NB4.

**Step 1 — Upload the data**  
Upload `credits.csv`, `keywords.csv`, and `movies_clean.parquet` to the Colab session storage.

**Step 2 — Run NB4**  
Parses the nested JSON fields, extracts directors, lead cast, and keywords, then saves four flat parquet files: `directors_clean.parquet`, `actors_long.parquet`, `lead_actors.parquet`, and `keywords_clean.parquet`.

**Step 3 — Run NB5**  
Performs the full creative intelligence analysis — director ROI rankings, actor profitability, star power correlations, genre interactions, and keyword analysis.

**Step 4 — Run NB6**  
Generates six publication-ready figures for the newsletter.

## 🔍 Questions Explored

- Which directors generate the highest median ROI across their filmography?
- Which directors have accumulated the most total box office revenue?
- Which lead actors consistently appear in the highest-grossing films?
- Does the size of a film's cast correlate with its commercial performance?
- Does the star power effect vary by genre?
- Which thematic keywords are associated with the highest audience ratings?
- Which keywords predict the highest average revenue?

---

## 📦 Intermediate Outputs

NB4 produces four parquet files consumed by NB5 and NB6:

| File | Description |
|------|-------------|
| `directors_clean.parquet` | Film-level table with director name, lead actor, cast size, and all financial fields |
| `actors_long.parquet` | Long table — one row per (film × top-3 billed actor) |
| `lead_actors.parquet` | Film-level table filtered to lead-billed actor only |
| `keywords_clean.parquet` | Long table — one row per (film × keyword) |
